# Hidden Farm Oasis

Create a clean, highly aesthetic, warm, and fully responsive one-page landing page for 'Hidden Farm Cafe', a famous nature & garden-themed cafe in Bukit Pakar, Bandung.

Use a natural, cozy botanical color palette (earth tones, leaf green, forest green, warm beige, and crisp white). Typography should feel modern, clean, and welcoming.

Please generate the following sections from top to bottom:

1. **Navigation Bar**:
   - Logo / Title: "Hidden Farm Cafe"
   - Links: "Home", "Suasana", "Menu", "Lokasi"
   - Right CTA Button: "📍 Petunjuk Rute" (links to Google Maps)

2. **Hero Section**:
   - Headline: "Nikmati Rehat Sejenak di Tengah Asrinya Kebun Bandung"
   - Sub-headline: "Sajian kopi pilihan & kehangatan suasana alam di Bukit Pakar Utara."
   - Primary CTA Button: "📍 Petunjuk Rute ke Kafe"
   - Secondary CTA Button: "📖 Lihat Menu"
   - Add a large featured image placeholder for the main garden cafe area.

3. **About / Atmosphere Section ("Suasana Kafe")**:
   - Title: "Oasis Hijau di Tengah Perbukitan"
   - Description highlighting the lush garden, fresh mountain air, pet-friendly outdoor seating, and cozy rustic vibes.
   - A grid layout with 2-3 image placeholders showing outdoor seats, plants, and cozy spots.

4. **Featured Menu Section ("Menu Favorit")**:
   - Section Title: "Pilihan Favorit Pengunjung"
   - Subtitle: "Nikmati aneka kopi, minuman segar, dan hidangan penutup terbaik kami."
   - Display 3-4 feature cards with image placeholders, item titles, short descriptions, and prices:
     * Signature Iced Coffee (Kopi susu aren khas Hidden Farm)
     * Artisan Pastry & Croissant (Pastry renyah cocok untuk teman ngopi)
     * Refreshing Botanical Mocktail (Minuman segar racikan buah & herba)
   - Add a prominent CTA Button under the cards: "📄 Lihat Menu Lengkap (PDF Drive)" that links to: https://drive.google.com/drive/mobile/folders/1XbcOW2KIn3fyYXGzH3b292tAE_ZSe7Tn

5. **Location & Operational Hours Section ("Lokasi & Jam Buka")**:
   - Include an embedded Google Maps iframe or map visual placeholder.
   - Info Card details:
     * Alamat: Jl. Bukit Pakar Utara No.40, Ciburial, Kec. Cimenyan, Kabupaten Bandung, Jawa Barat 40198
     * Jam Operasional: Setiap Hari (Senin - Minggu) 07.30 - 23.00 WIB
     * Catatan: Area parkir tersedia & Pet Friendly 🐶

6. **Footer**:
   - Social link: Instagram (@hiddenfarm.cafe)
   - Email: hiddenfarm.bdg@gmail.com
   - Copyright text: "© 2026 Hidden Farm Cafe Bandung. All rights reserved."

Ensure smooth scrolling behavior when clicking navigation links to jump between sections on the page. Make sure layout is fully optimized for mobile screens.
